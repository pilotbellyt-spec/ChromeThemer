# ChromeThemer: Firefox userChrome.css on Chrome.

ChromeThemer allows you to import userChrome.css or userChrome.js to Chrome's shell, allowing you to theme it however you want.



## Requirements

- The "webium" flag MUST be enabled in chrome://flags if you want the theme to be persistent without a shortcut, if combined titlebar is enabled, you will need a shortcut no matter what.



## Instructions

- Install ChromeThemer
- Set the webium flag to enabled
- Find or create a theme you like
- select the Chrome/Chromium binary
- select the theme folder
- click apply.
- Your theme should now be applied.
- if you have combined titlebar enabled, or you dont want the custom theme to be always active you can choose to save a shortcut, simply save it where you choose, then run it from there.


## Usage

- use any theme you want, or create one
- 2 sample themes are also attached: graphite, a pretty standard dark theme, and chrome 68 dark, which replicates the old Chrome pre-M69 design, but in dark mode
